# CodeAlpha Data Visualization

## 📊 Sales Analytics Dashboard

This project is part of the CodeAlpha Data Analytics Internship.

The project analyzes sales data and presents the results through an interactive dashboard built with Python, Pandas, Plotly, and Streamlit.

## 🎯 Project Objectives

- Analyze sales performance
- Visualize monthly sales trends
- Compare sales across regions
- Compare sales across product categories
- Analyze product-wise sales
- Compare sales and profit
- Provide interactive filters for data exploration



🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Streamlit


📈 Dashboard Features
KPI Cards
The dashboard displays:
- Total Sales
- Total Profit
- Total Quantity
- Total Orders
Interactive Filters
Users can filter the dashboard by:
- Region
- Category
Visualizations

The dashboard includes:
1. Monthly Sales Trend
2. Sales by Category
3. Sales by Region
4. Sales by Product
5. Sales vs Profit
Data Table
Users can view the filtered sales data directly in the dashboard.


📊 Dataset
The dataset contains sales information including:
- Order ID
- Date
- Region
- Category
- Product
- Sales
- Quantity
- Profit
